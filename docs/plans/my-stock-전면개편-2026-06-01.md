## Context

현재 my-stock은 기능적으로 동작하지만 다음 문제들이 누적되어 유지보수성·안정성·성능에 심각한 위협이 되고 있다:

- **보안**: API 라우트 전체에 인증 로직 없음 (middleware 통과 시 직접 호출 가능)
- **성능**: 포트폴리오 N+1 KIS API 조회, 직렬 DART 호출로 최대 20초 응답 지연
- **타입 안전성**: 주요 섹션 컴포넌트 6개가 `any` 타입, `Record<string, unknown>` 남용
- **코드 중복**: Google OAuth 토큰 생성 로직 3곳, 종목코드 검증 정규식 5곳 이상
- **아키텍처**: API 응답 형식 비표준, 캐시 전략 불일관, 에러 처리 불일치
- **UI/UX**: 413줄짜리 TickerDetailContent, 로딩/에러 상태 불일관, 미구현 컴포넌트

**전면 개편 목표**: 코드 품질·보안·성능을 프로덕션 수준으로 끌어올리고, 향후 기능 추가가 쉬운 구조로 재정비

## 단계별 구현 계획

### Phase 1 — 핵심 인프라 정비 (기반 작업)

다른 모든 단계가 이 Phase에 의존한다.

#### 신규 파일

| 파일 | 역할 |
|------|------|
| `lib/config.ts` | 환경 변수 중앙 관리 + 시작 시 검증 (`requireEnv()`) |
| `lib/google-oauth.ts` | Google OAuth JWT 토큰 공통 함수 (3곳 중복 제거) |
| `lib/logger.ts` | 중앙 로거 (마스킹, 타임스탬프, Vercel 로그) |
| `lib/api-response.ts` | API 응답 헬퍼 (`ok`, `badRequest`, `unauthorized`, `serverError`) |
| `lib/auth-guard.ts` | API 라우트 인증 가드 (`requireAuth(request)`) |
| `lib/stock-utils.ts` | 종목코드 정규화·검증 공통 함수 (5곳 중복 제거) |

#### 수정 파일

- `lib/google-sheets.ts` — OAuth 로직 → `lib/google-oauth.ts`로 위임
- `lib/ai-cache.ts` — OAuth 로직 위임, TTL(7일) 추가
- `lib/kis/token-store.ts` — OAuth 로직 위임
- `app/api/**` 전체 — `requireAuth()` 추가, `api-response.ts` 헬퍼 적용

### Phase 2 — 데이터 레이어 버그 및 성능 수정

#### 2-1. KST 타임존 버그 수정 (`lib/ticker-cache.ts:86-104`)

```typescript
// 현재 (버그): UTC 오프셋 조정 후 setUTCHours 사용
const kstNow = new Date(utc.getTime() + 9 * 60 * 60 * 1000);
kstNow.setUTCHours(MARKET_OPEN_HOUR, 0, 0, 0);  // ← 잘못됨

// 수정: Intl API 사용
const kstNow = new Date(new Date().toLocaleString("en-US", { timeZone: "Asia/Seoul" }));
```

#### 2-2. 종목코드 유틸 통합 (`lib/stock-utils.ts`)

5곳 이상 중복 정규식 → 단일 함수:
```typescript
export function normalizeStockCode(input: string | undefined): string | undefined
export function isValidStockCode(code: string): boolean  // /^\d{6}$/ + !== "000000"
```

수정 대상: `lib/portfolio-summary.ts:24-31`, `app/api/ai/trading-guide/route.ts:82`, `app/api/fundamental/valuation/route.ts:25`, `app/api/fundamental/financials/route.ts:24`, `app/api/dart/financials/route.ts:91`

#### 2-3. Promise.allSettled 전환 (`app/api/fundamental/route.ts:116-135`)

```typescript
// 현재: Promise.all → KIS/DART 하나 실패 시 전체 503
// 수정: Promise.allSettled → 부분 실패 허용, 성공 데이터만 반환
const [priceRes, dartRes, ratioRes, balanceRes, incomeRes, dailyRes] =
  await Promise.allSettled([getPriceInfo(code), getDartTrendOnly(code), ...]);
const priceInfo = priceRes.status === "fulfilled" ? priceRes.value : null;
```

#### 2-4. DART 직렬 호출 병렬화 (`app/api/fundamental/route.ts:133-135`)

현재 `dartTrend` 완료 후 순차 호출 → 두 단계 병렬화:
1. `getDartTrendOnly(code)` 먼저 시작
2. corpCode 확보 후 즉시 `getDartPreliminaryAndDocument(corpCode)` 시작

#### 2-5. POST 입력 검증 강화 (`app/api/sheets/transactions/route.ts`)

- Quantity/Price: 양수 정수 검증
- Date: `YYYY-MM-DD` 형식 검증
- Type: `"매수" | "매도" | "배당"` 열거형 제한
